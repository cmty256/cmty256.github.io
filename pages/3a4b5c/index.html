Gradle常用命令

# Gradle 常用命令

Gradle 命令以 gradlew（Wrapper）或 gradle（本地安装）开头，后接 Task 名称或参数。本文以 gradlew 形式给出，Windows 直接用 gradlew，Linux/Mac 用 ./gradlew。

# 基础构建命令

命令 说明 Maven 对应
gradlew clean 清理 build/ 目录 mvn clean
gradlew build 完整构建（编译 + 测试 + 打包 + 检查） mvn package
gradlew assemble 编译并打包（不运行测试） mvn package -DskipTests
gradlew compileJava 编译主源代码 mvn compile
gradlew compileTestJava 编译测试源代码 mvn test-compile
gradlew test 运行单元测试 mvn test
gradlew check 运行所有检查（测试 + 代码分析等） mvn verify
gradlew jar 打包成 JAR mvn package
gradlew bootJar 打包可执行 Spring Boot JAR spring-boot:repackage
gradlew bootRun 本地运行 Spring Boot 应用 spring-boot:run

gradlew build 是最常用的命令，它会依次执行 compileJava → compileTestJava → test → jar，类似 mvn clean package。

# 命令执行顺序

Gradle 的 Task 之间有依赖关系，执行一个 Task 会自动先执行它依赖的 Task：

gradlew build
  → compileJava
  → processResources
  → classes
  → compileTestJava
  → processTestResources
  → testClasses
  → test
  → jar

# 常用参数

参数 说明 Maven 对应
-x <task> 排除某个 Task 不执行 -
--exclude-task <task> 同上 -
-P<name>=<value> 传入项目属性 -D<name>=<value>
-D<name>=<value> 传入系统属性 -D<name>=<value>
--no-daemon 不使用 Daemon 进程 -
--offline 离线模式，不访问网络 -o
--refresh-dependencies 强制刷新依赖缓存 -U
--parallel 并行构建 -T
--build-cache 启用构建缓存 -
--info 输出详细信息 -X
--debug 输出调试信息 -
--quiet / -q 静默模式 -q
--stacktrace 输出完整异常栈 -e
--continue 遇到失败继续执行后续 Task -
--dry-run 只打印 Task 执行计划，不实际执行 -

# 多模块项目命令

命令 说明
gradlew :app:build 只构建 app 子项目
gradlew :app:bootRun 运行 app 子项目
gradlew :app:test 只测试 app 子项目
gradlew :app:dependencies 查看 app 子项目的依赖树

Gradle 用 :项目名:task 的路径形式指定子项目的 Task，类似 Maven 的 -pl module。

# Gradle 构建生命周期

Gradle 构建分为三个阶段：

# 1. 初始化阶段（Initialization）

读取 settings.gradle，创建 Project 对象。

# 2. 配置阶段（Configuration）

执行所有 build.gradle 脚本，构建 Task 依赖图。此阶段会执行脚本中的所有顶层代码和 Task 的配置块。

# 3. 执行阶段（Execution）

按依赖顺序执行选定的 Task 及其依赖的 Task。

初始化阶段          配置阶段              执行阶段
settings.gradle  →  build.gradle       →  task 执行
创建 Project        构建 Task 依赖图        doFirst / doLast
1
2
3

重要：配置阶段的代码每次构建都会执行（无论运行哪个 Task）。因此不要在配置阶段写耗时操作，耗时逻辑必须放在 doFirst / doLast 中。

# Gradle Daemon

Gradle 默认使用 Daemon 进程来加速构建。Daemon 是一个常驻后台的 JVM 进程，避免每次构建都启动新 JVM。

# Daemon 的工作原理

第一次构建：启动 Daemon → 执行构建 → Daemon 保持运行
后续构建：复用 Daemon → 直接执行构建（省去 JVM 启动时间）

# Daemon 配置

在 gradle.properties 中配置：

# 启用 Daemon（默认已启用）
org.gradle.daemon=true
# Daemon 空闲超时时间（毫秒），默认 3 小时
org.gradle.daemon.idletimeout=10800000

# Maven → Gradle 命令速查表

功能 Maven Gradle
清理 mvn clean gradlew clean
编译 mvn compile gradlew compileJava
测试 mvn test gradlew test
打包 mvn package gradlew build 或 gradlew jar
安装到本地仓库 mvn install gradlew publishToMavenLocal
部署到远程仓库 mvn deploy gradlew publish
跳过测试 mvn package -DskipTests gradlew build -x test
依赖树 mvn dependency:tree gradlew dependencies
强制更新依赖 mvn build -U gradlew build --refresh-dependencies
离线模式 mvn build -o gradlew build --offline
指定模块 mvn build -pl module gradlew :module:build
激活 Profile mvn build -P prod gradlew build -Penv=prod
运行 Spring Boot mvn spring-boot:run gradlew bootRun
打包 Spring Boot mvn package gradlew bootJar
