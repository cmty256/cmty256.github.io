TypeScript基础

# TypeScript基础

Vue3 使用 TypeScript 重构了大量代码，学习 Vue3 前有必要了解 TypeScript 的基础知识。

# 1. TypeScript

# 1) 动态类型的问题

前面我们讲过 js 属于动态类型语言，例如

function test(obj) {    
}
1
2

obj 可能只是个字符串

test('hello, world')
1

obj 也有可能是个函数

test(()=>console.log('hello, world'))
1

obj 类型不确定，就给后期使用者带来了麻烦，一旦参数传不对，代码就崩溃了

动态类型意味着

  • 运行代码时才知道发生什么 (running the code to see what happens)

静态类型意味着

  • 在代码运行前，就对它的行为做出预测 (make predications about what code is expected before it runs)

下面的 typescript 代码，就在代码运行前对参数加入了约束限制

function test(msg : string) {
}
1
2
  • 限制了参数只能做 string 那些事
function test(msg : Function) {
  msg()
}
1
2
3
  • 限制了参数只能做函数那些事

# 3) 类型

类型 例 备注
字符串类型 string
数字类型 number

# 泛型

下面的几个类型声明显然有一定的相似性

interface RefString {
  value: string
}

interface RefNumber {
  value: number
}

interface RefBoolean {
  value: boolean
}

const r1: RefString = { value: 'hello' }
const r2: RefNumber = { value: 123 }

函数定义也支持泛型

function ref<T>(n: T): Ref<T> {
  return { value: n }
}

const v1 = ref("hello"); 	// Ref<string>
const v2 = ref(123.3333);	// Ref<number>

v1.value.toLocaleLowerCase()
v2.value.toFixed(2)

# 继承与接口

interface Flyable {
  fly(): void
}

  name: 沉梦听雨

    this.name = name
  }

class Bird extends Animal implements Flyable {
